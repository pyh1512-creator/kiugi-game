# 🍔 박예훈 키우기 (Feed & Grow Yehoon)

> **세상에서 가장 웃기고 끝없이 커지는 박예훈을 맛있는 음식으로 무한 육성해보세요!**  
> 자취방에서부터 다중우주 절대신까지 진화하는 무한 성장 병맛 방치형/클리커 웹 게임입니다.

---

## 🎮 주요 게임 특징
- **10,000 레벨 무한 성장 & 16단계 전설 애니메 크로스오버 진화**:
  - 드래곤볼 (손예훈, 초사이어인, 완성형 무의식의 극의)
  - 나루토 (구미 차크라 모드 & 나뭇잎 서클릿)
  - 블리치 (만해 천쇄참월 호로화)
  - 원피스 (태양의 신 니카 기어 5)
  - 귀멸의 칼날 (해의 호흡 히노카미 카구라)
  - 주술회전 (저주의 왕 료멘 스쿠나)
  - 나 혼자만 레벨업 (그림자 군주 성예훈)
  - 헌터x헌터 (극한 제약과 서약 곤육몬)
  - 페이트 (영웅왕 게이트 오브 바빌론)
  - 원펀맨 (진심 시리즈 사이타마)
  - 에반게리온 (초호기 각성 유사신화 & AT 필드)
  - 천원돌파 그렌라간 (초천원돌파 나선신)
  - Lv.10000 MAX: 전지전능 애니메 절대신 박예훈
- **실시간 반응형 캐릭터 그래픽**: 플레이어의 실제 얼굴 사진과 감정 표정이 애니메이션 복장에 완벽 싱크!
- **자동 레벨업 시스템**: 경험치가 채워지면 버튼 클릭 없이도 즉시 자동 레벨업 & 보너스 골드 지급!
- **모바일 완벽 지원**:
  - 반응형 Dynamic Viewport (`100dvh`) & Safe-Area Inset 대응
  - 모바일 터치 드래그앤드롭 음식 먹이기 및 뱃살 터치 리액션
- **풍성한 사운드 & 파티클**: Web Audio API 기반 효과음 및 실시간 폭죽 파티클

---

## 🛠 기술 스택
- **프론트엔드**: HTML5, Vanilla CSS3 (Neo-Brutalist & Juicy Game Aesthetics), Vanilla JavaScript (ES6+)
- **그래픽**: Dynamic Vector SVG + Canvas 2D Particle Engine
- **사운드**: Web Audio API Procedural Synthesizer
- **배포**: GitHub & Vercel
